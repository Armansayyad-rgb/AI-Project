# Use Cases

RALG should be evaluated first in narrow, high-value document workflows.

## Best-fit early use case

### Manufacturing and industrial technical-document Q&A

Example documents:

- machine manuals
- maintenance SOPs
- safety procedures
- troubleshooting guides
- training documents
- internal process notes

Example questions:

- "What should a technician check before restarting this machine?"
- "Which safety step is required before opening the panel?"
- "What does the manual say about overheating?"
- "Is this procedure allowed under the SOP?"
- "What document supports this answer?"

Why this fits:

- answers can save time
- documents are dense
- privacy matters
- citations are important
- usage may be low-volume but high-value

## Other possible use cases

| Use case | Fit |
|---|---|
| Internal technical support | Good if documents are clean and questions repeat |
| Compliance document lookup | Good, but needs careful validation |
| Product manual assistant | Good for narrow product lines |
| Research notes assistant | Useful, but harder to monetize early |
| Legal/medical/financial Q&A | Avoid early because risk is high |

## Recommended early demo

Use a small set of public or synthetic technical documents and show:

- answer with cited support
- refusal when evidence is missing
- comparison with baseline retrieval
- latency on modest hardware
